# 六月会话功能补充记录

整理时间：2026-06-11

本文件记录根据 2026 年 6 月可读会话、请求转储和当前小昭 2.0 技能文件补齐的功能点。

## 采用的规则版本

- 以 2026-06-08 的小昭招聘机器人2.2说明和 `skills/xiaozhao-robot-2/SKILL.md` 为准。
- 推荐牛人只处理 `最新` 标签，不再处理 `推荐` 标签。
- 每个开放岗位在 `最新` 标签累计打开 30 份在线简历后切换岗位。
- 不再使用本地每日 120 份总额度作为停止条件。
- 启动或恢复流程时最多允许刷新一次 BOSS 页面用于同步状态；岗位切换和循环继续不刷新、不重载页面。

## 已补齐的飞书功能

- `@小昭 /help`、`@小昭 你有什么功能`
- 日报查询：`@小昭 /日报 2026/06/05`、`@小昭 今天的日报`、`@小昭 昨天的日报`
- 周报查询：`@小昭 /周报 2026/06/05`

- 反馈记录，并自动生成需求单
- 每天 09:00 未完成需求/Bug 合并报表

## 已补齐的 CLI 命令

通过 `skills/zhipin-boss-recruitment-bot/scripts/sqlite_store.py` 提供：

```bash
python3 skills/zhipin-boss-recruitment-bot/scripts/sqlite_store.py --db data/.zhipin-copilot/recruitment.sqlite3 jd-library --action 查看
python3 skills/zhipin-boss-recruitment-bot/scripts/sqlite_store.py --db data/.zhipin-copilot/recruitment.sqlite3 record-feedback --text "反馈内容"
python3 skills/zhipin-boss-recruitment-bot/scripts/sqlite_store.py --db data/.zhipin-copilot/recruitment.sqlite3 create-ticket --kind bug --text "Bug内容"
python3 skills/zhipin-boss-recruitment-bot/scripts/sqlite_store.py --db data/.zhipin-copilot/recruitment.sqlite3 create-ticket --kind xq --text "需求内容"
python3 skills/zhipin-boss-recruitment-bot/scripts/sqlite_store.py --db data/.zhipin-copilot/recruitment.sqlite3 list-tickets --kind bug
python3 skills/zhipin-boss-recruitment-bot/scripts/sqlite_store.py --db data/.zhipin-copilot/recruitment.sqlite3 update-ticket --kind bug --ticket-id 1 --action complete
python3 skills/zhipin-boss-recruitment-bot/scripts/sqlite_store.py --db data/.zhipin-copilot/recruitment.sqlite3 update-ticket --kind xq --ticket-id 1 --action complete
```

未完成工单日报：

```bash
python3 skills/zhipin-boss-recruitment-bot/scripts/unfinished_ticket_report.py --db data/.zhipin-copilot/recruitment.sqlite3 --dry-run
```
